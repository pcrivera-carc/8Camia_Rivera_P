## Description
It's an algorithm to calculate the hypotenuse of
a triangle given the measurements of the three sides.


## How to Run
To run the program, you need to input the length of each
side, then the algorithm does the calculating.


## Input Needed
You need to input the measurement of each
side of the triangle.


## Sample Output
If I input a = 3, b = 4 it will calculate me the answer
which is 5.
